## 📖 نبذة عن التطبيق (Overview)

تطبيق **MWYD** هو الحل الهندسي الأمثل والمتكامل لتحميل ملفات الفيديو والصوت من أكثر من 1,000 منصة وموقع ويب (بما يشمل YouTube، TikTok، Instagram، Facebook، X/Twitter، SoundCloud، وغيرها) بأعلى جودة ممكنة (تصل إلى 4K و 1080p بمعدل 60 إطاراً في الثانية).

تم بناء وتطوير التطبيق اعتماداً على أحدث تقنيات أندرويد المعاصرة مع واجهة مستخدم حديثة بنظام **Material Design 3**، داكنة وأنيقة مع لمسات ذهبية ملكية، ودعم كامل ومرن للغة العربية (RTL).

---

## 🌟 الميزات الرئيسية (Key Features)

- 🎬 **دقة فائقة تصل إلى 4K و 1080p**: جلب أعلى مسارات الفيديو والصوت ودمجها تلقائياً عبر مكتبة FFmpeg لإنتاج فيديو عالي النقاء.
- 🎧 **استخراج الصوت الاحترافي**: تحويل الفيديو إلى صيغ MP3 (320kbps) و M4A و Opus و FLAC مع تضمين غلاف الألبوم وبيانات الفنان الوصفية تلقائياً.
- ⚡ **محرك تنزيل متعدد المسارات (Multi-Threaded)**: استغلال السرعة القصوى لاتصال الإنترنت مع إمكانية تحديد السرعة والتحميل المتزامن للملفات المتعددة.
- 🔄 **نظام الاستئناف الذكي والصمود الشبكي**: حفظ تقدم التنزيل وتجديد الروابط المباشرة تلقائياً عند انقطاع الشبكة أو تبديل شبكات الاتصال.
- ✂️ **قص واقتصاص الفيديو قبل التنزيل**: تحديد أجزاء معينة من المقطع لتحميل الدقائق المطلوبة فقط وتوفير باقة البيانات.
- 🌐 **دعم الترجمة والدبلجة الصوتية**: تضمين ملفات الترجمة (Subtitles) باللغة العربية واختيار المسارات الصوتية المتعددة.
- 📱 **تنزيل فوري عبر المشاركة**: شارك أي رابط مباشرة من أي تطبيق (يوتيوب، تيك توك، إلخ) إلى MWYD للتحميل الفوري دون فتح التطبيق يدوياً.
- 🔒 **مجاني وخالٍ تماماً من الإعلانات**: تطبيق مفتوح المصدر 100% بموجب رخصة GPL-3.0، بدون إعلانات، بدون برمجيات تتبع، وبحماية كاملة للخصوصية.

## 🛠️ بناء المشروع من المصدر (Build from Source)

يتطلب بناء التطبيق بيئة Android SDK مع JDK 17:

```bash
# استنساخ المستودع
git clone https://github.com/monestw-cell/mwyd-media-downloader.git
cd mwyd-media-downloader

# بناء حزمة الـ APK للإصدار
./gradlew assembleGithubRelease
```

ستجد ملف الـ APK الناتج في المسار:
`app/build/outputs/apk/github/release/`
